# 深空猫舍

**一句话描述**　在深空当铺养猫、喂猫、选育下一代。今天把你的货踢下展柜的那只猫，明早也许会在柜台上留给你一件宝贝。

**核心体验**　玩家能做的，是照料眼前这只猫，观察它，再选择想让哪两只猫留下后代。猫愿不愿意被抱、喜欢坐在哪里、晚上出不出门，都由它自己决定。一只畏噪的斑猫也许总往货架后面钻，偶尔叼出一只老鼠；它的幼崽可能长着同样的花纹，却偏爱人声，常常自己爬上柜台。选育的乐趣就在于等这些差异慢慢显现。以下为 2026-11-18 设计基线，基础寿命按游戏周计算，事件概率、物价和性状修正幅度留待试玩调平。[开发与创意工坊发布](开发与创意工坊发布.md)

### 玩家实际怎么做

取消猫舍和宠物店共用的「照料与育种」面板。打开猫舍可看到住猫的格子和装上的设备。双击一只猫可看它自己的遗传图。

| 想做的事 | 新操作与可见结果 |
| --- | --- |
| 喂猫、扩猫舍 | 猫的基础食量为原版老鼠的 3 倍，每天 195 千卡，饱腹容量 1500 千卡。猫粮占 2×2 格，提供 240 千卡。吃猫粮可促进幼猫成长、延长成年期和提高夜行收获概率。分配器按原版设置投喂，猫舍食物先供繁育间，再供猫窝和回来的猫。猫舍本体占 4×3 格，猫窝初始 8×4。每块金属锭在底部加一行，共可升级六次，最高 8×10 |
| 自然繁育 | 每座猫舍单独结算喂食及配种，猫窝自行外出的猫仍在原来的组。用韧棉织物给单座猫舍加建 6×4 的独立繁育隔间，逐行扩到 6×10。猫窝和繁育间的受孕概率为 50% 和 70%，最迟在第 4 次或第 3 次合格尝试受孕。每窝按母猫的遗传倾向随机抽取 1–8 只 |
| 看血亲、做测序 | 双击猫打开个体详情和三代遗传图。点击猫咪立绘查看分组性状，沿不同颜色的连线查双亲、祖辈和曾祖辈。对实际测序过的个体，按染色体和亲本来源展示详细 0/1 位串 |
| 回收猫毛和制布 | 猫毛落在猫所在的容器。独立的 3×3 猫毛加工器装电池后，每晚自动把可取的猫毛移入进料格。每 10 份猫毛和 4 千焦产出 1 份原版韧棉织物，出料格只供取走产品 |
| 领养、补货、卖猫 | 夜访宠物店能看见具体可领养的猫，用品和猫按柜台实物报价。爱猫人士会提出一至三项选猫需求。部分顾客只收幼猫、成猫或稳重的老年猫。年龄条件只决定能否成交。每满足一项参与估价的偏好，在平时估价上增加 50%。有估价偏好但零项满足时出价为原价的 70%。正常议价，收款后才转移个体所有权 |
| 命名、绝育、遗弃 | 用原版蓝色标签打印机给猫命名。对成年或老年猫使用剪线钳可绝育。把活猫拖进原版垃圾桶会遗弃它，家谱继续保留这个个体。自然死亡留下的猫尸可走黑市清洁服务 |
| 得知猫昨晚做过什么 | 把关店和入睡分开。关店后店主照常走夜间地图、逛店；确认入睡后猫才自主夜行。次晨从原版晨报读猫做了什么，实际生效的阵营声望变化接在对应动作后。实物优先放在后区柜台，放不下时放到店内收纳 |

**从宠物店出身跑一遍。** 打开基础猫舍，左侧专用槽已装好一台原版喂食机。一公一母两只成猫和 4 份猫粮都在 8×4 猫窝里。猫可以直接吃窝里的粮，夜间有机会自然交配。母猫分娩后按自身基因隔满 1～3 个完整游戏日，再参与配种。以后攒钱买猫毛加工器，装入电池，等猫毛攒够后次晨可取韧棉织物。店主也可以直接购买韧棉织物加建或扩建繁育隔间。幼猫出生后，双击它就能看性状，再沿立绘连线看双亲及已知祖辈。

### 接入顺序与验收

1. 验证外部占格、普通空间和繁育隔间各自的纵向上限。达到上限时不扣材料。旧档普通空间不足 8 列时补到 8 列，保留已购空间和摆放位置。新外形放不下的旧猫舍，待玩家腾出空间后再替换。
2. 检查两座猫舍分别消耗各自的食物，猫窝自发外出的猫仍在原组配对，繁育间只匹配同住的猫并获得受孕增益。重复测试同样的母猫基因能得到不同的窝数，低倾向常见小窝、高倾向常见大窝。旧档在途育种沿用原出生时间、随机种子和预定窝数。塞满母猫所在的猫舍，确认放不下的幼猫到柜台。
3. 检查猫在猫窝、繁育间和店内其他容器时的掉毛位置。验证加工器有电收毛、耗电制布、出料取物、满仓保料及新档库存读回。

## 第一次遇见猫

新游戏的「宠物店」出身给一对成猫和 8 份猫粮，双猫直接住在猫舍里。两只起始猫各自生成基因，无共同家谱记录。日常照料和育种见[原版交互改版](#原版交互改版)。

| 入口 | 玩家经历 |
| --- | --- |
| 夜访宠物店 | 打烊后亲自去宠物店，从右侧货板挑实物并找老板结账。每次夜访随机生成 6 只幼猫、2 只成猫，常备一座猫舍。第一只猫可免费领养，用品和猫在返店时由老板送到当铺 |
| 老板来访 | 还没得到过猫时，宠物店老板可能来到当铺当面赠送第一只猫。来访使用夜间宠物店的老板立绘 |
| 每周供货 | 从第 7 天起，宠物店老板每周到当铺，在前柜台摆放可以领养的猫和猫舍用品，按原版供货价出售 |
| 王尔德的推荐 | 在王尔德的「推荐」里花 750 信用点开启「猫咪爱好者」，领取一只猫和配套物品 |
| 宠物店出身 | 开新档时可选「宠物店」。开局一对成年公母猫同住普通隔间，第一晚就有机会自然育种 |

来店的「猫咪爱好者」可以一次购买柜台上多只符合买家限制的活猫，使用原版柜台批量出售，整批共用同一份来访预算。预算与原版普通市民相同，随游戏天数和店铺经营进度增长。顾客通过对话说明年龄、毛长、外观或性格需求，可组合提出。成年估价以 60 信用点为基数，每个可见外观特征按固定金额独立累加。详情逐项显示外观加减价。纯黑、纯白被毛各加 24，其他整身纯色加 18，鼻斑扣价。烟色、银渐层、银壳色分别加 24、20、30，花色爱好者也可能点名要其中一种。性格等非外观标签只在买家提出相应需求时参与交易。幼猫基础估价加 40%，老年猫减 35%。顾客的年龄条件用于筛选个体。满足一、二、三项估价偏好时，出价分别为平时的 1.5、2、2.5 倍。有估价偏好却零项满足时为 0.7 倍，只有年龄条件时按正常估价。宠物店的商品结账时使用原版供应商加价。猫粮基础价为 30，普通难度下向宠物店购买为每份 45 信用点。首次赠猫资格看本周目的获猫经历，王尔德服务的赠礼随开启发放一次。

## 看一只猫，读懂一只猫

| 玩家手里有什么 | 能知道什么 |
| --- | --- |
| 刚遇见一只猫 | 逐只手动查看它的外观、年龄阶段、饱腹等基础状态。在店里亲眼看见它抓鼠、翻货或躲开伸来的手，也是一条线索 |
| 双击一只猫 | 打开这只猫的遗传图，往上追三代，依次展示已知的双亲、祖辈和曾祖辈。点击任意猫的正面立绘卡片，在右侧读外观、性格、习性和状态 |
| 为某只猫做基因测序 | 开启原版扫描仪并实际查看目标个体。每只猫保存首次扫描时的 0/1 序列，按染色体和亲本来源在对应家谱节点查看 |

图按个体 ID 连线，共享祖先保留真实亲缘线，未知血亲停在线索中断处。已出售、遗弃或死亡的猫保留亲缘、性状档案和在场时取得的测序记录。某只血亲在失去可扫描的个体前若从未测序，它的详细序列永久未知。打开家谱、扫描焦点猫或推断亲缘都不会给其他节点补发测序记录。

## 遗传与自然繁育

**基因与选育是模组的玩法核心。** 每条染色体按有序的 0/1 位串保存。常染色体六组共 91 对二进制位点，另有 6 个 X 独有位点与 2 个 Y 独有位点。幼崽每组从双亲各继承一条常染色体，传下的序列可在相邻位之间重组。母猫的两条 X 可重组后传出一条 X，公猫的 X 和 Y 各自传递。幼崽按继承结果确定性别，XX 为母猫，XY 为公猫。同窝逐只抽取。

每个物理位的 1 为显性，0 为隐性。有两份时，0/0 显现 0，其余组合显现 1。多种颜色、形态或强度由多个位置的组合得出。同一序列片段可影响多个性状，控制位组合只调节指定效果。起始携带率、显现条件和整套组合的传递稳定性分开设计。继承与选育流程见[猫猫基因组设计](猫猫基因组设计.md)，具体位点、组合规则和验收用例见[猫猫基因表达规则](猫猫基因表达规则.md)。

| 性状 | 屏幕上能观察到的例子 |
| --- | --- |
| 外观 | 程序根据基因表达计算骨架、胖瘦、脸颊厚度、耳形、毛色、纹路与白斑。圆胖的猫坐下时腹部贴近后腿，清瘦的猫能看出腰线，幼猫趴下时也能从背部厚度看出差异。后代可以长着一方的毛色和另一方的身形。被白斑盖住的花纹可能在下一代重新显出来 |
| 潜能 | 对细小动静敏感、反应快的组合让某只猫更容易抓到老鼠。它仍可能同时爱翻柜子、亲近来客 |
| 性格 | 好奇与谨慎可以同时显现。猫会在安静货架上拨弄一小瓶梦尘，遇到吵闹的人群又躲开 |
| 体质 | 食量、耐力、恢复速度和对水质的反应，体现在成长、休息和夜行后的状态上 |
| 稀有性状与缺陷 | 部分稀有性状和缺陷依赖隐性位。例如无毛、恢复慢、对坏水敏感分别要求对应的两份值都为 0。某些效果在出现 1 时生效，例如抑色带来的易躁 |

**一只猫的毛发、眼睛与花色怎样组合**

| 外观性状 | 在猫身上的表现 |
| --- | --- |
| 毛长与肤色 | 短毛贴合身体，长毛在颊边、颈胸和尾部形成更蓬松的轮廓。无毛猫沿用该个体的头身比例、五官和体态，颊缘与颈胸沿皮肤收拢。额褶顺着眉弓，颈褶从下颌转向颈侧，幼猫的褶较浅。虎纹、拼色和白手套随毛发隐藏，无毛猫仍可将这些花色传给有毛的幼崽。[脸颊与颈部实拍](cat-lab-hairless.png) |
| 瞳色 | 琥珀、金黄、铜棕、榛褐、绿、青绿和蓝均可同瞳或异瞳。左右按猫自身区分，例如左蓝右绿的猫正面朝向玩家时，蓝眼在画面右侧。变色范围是虹膜，瞳孔、眼线和高光保留 |
| 眉纹与耳形 | 眉弓上可出现原画眉、细眉、浓眉、弯月眉或一对眉点，也可以没有眉纹。无毛时眉纹更淡。耳形有立耳、微折耳、折耳三种，耳尖向前下方翻折。耳廓高度另算，同样高的两只耳朵也能有不同的折幅 |
| 耳色与鼻斑 | 内耳可以随毛色或肤色变深，也可以单独显出粉色、烟灰或墨黑。鼻头可呈粉色、黑色或粉底黑斑。鼻斑有自己的分布编号，改变被毛的花纹编号时，原来的鼻斑仍留在原处。墨黑纯色配深色内耳与黑鼻可以形成全黑猫，瞳色独立表达 |
| 底色与花纹 | 底色包括暖橘、奶油、白、棕、蓝灰、银灰和黑等。纯色时全身沿用底色。渐层从背部较深的毛尖色过渡到较浅的下腹。虎斑沿额头、体侧和尾巴分布。拼色让两种颜色形成不规则色块，三花还带有独立分布的白斑 |
| 定位花色 | 白手套从爪尖向上覆盖，可与虎斑或拼色同时显现。白围脖集中在颈胸。乌云盖雪呈现深色背、浅色下巴和白胸腹，坐姿正面能看到胸前的白色，转身能看到深背 |
| 传统黑白花色 | 踏雪寻梅为黑身白爪，雪里拖枪为白身黑尾，挂印拖枪在白身黑尾上多一枚额斑。特殊花色按最终显现的名称计一次，花色爱好者可指定这些花色 |
| 重点色、梵花与高白斑 | 重点色的脸、耳、四足和尾比躯干深。梵花的大块颜色集中在头顶和尾巴，头顶两斑之间留白。高白斑还会在肩背或侧腹留下有色斑块，白色覆盖量和分布编号共同决定每只猫留下多少颜色、落在哪边 |
| 斑点虎斑 | 躯干两侧长出深色圆斑或椭圆斑，额头、脸颊、四肢和尾巴仍可见条纹。斑点色和密度参与表达，转动模型能看到背面与另一侧的斑点 |

实验室可在「体型与五官」切换眉纹和耳形，在「毛长与配色」查看内耳和鼻斑。单击「毛色与花纹」里的「试试全黑猫」即可查看纯黑的耳、脸、身体和尾巴。正面格内图与可旋转的模型使用同一组外观参数。[五官与花色实拍](cat-lab-face-and-markings.png)

外观参考取自猫协会的品种标准。孟买猫的黑色被毛和黑鼻用于全黑样例。重点色与梵花分别参考四端着色、头尾着色的分布，高白斑参考双色标准，躯干斑点与尾环参考埃及猫。这些形态在模组里可以跨品种组合。[CFA 孟买猫](https://cfa.org/breed/bombay/) · [CFA 重点色短毛猫](https://cfa.org/breed/colorpoint-shorthair/) · [GCCF 土耳其梵猫](https://www.gccfcats.org/getting-a-cat/choosing/cat-breeds/turkish-van-turkish-vankedisi/) · [GCCF 双色标准](https://www.gccfcats.org/wp-content/uploads/2022/07/OriBi-SOP-July-2022.pdf) · [CFA 埃及猫](https://cfa.org/breed/egyptian-mau/)

花纹分布是个体外观的一部分。即使两只同窝幼猫都长成橘黑白三花，橘斑也可能分别落在左脸和右肩。同一只猫转身、搬动或读档后，这些色块应留在原处。长大时按成猫体表重新计算花纹，保留它的配色、花纹分布参数和双眼颜色。

无毛猫转身时，肩胸之间、大腿根与胁腹之间的明暗应连续过渡。坐姿前腿仍能看出肘部，趴姿前爪落地，蜷起的后腿有轻微隆起。实验室用同一层皮肤连接躯干和四肢根部，调节胖瘦时，连接处跟着相邻部位一起变形。[暖沙色无毛猫的肩髋实拍对照](cat-lab-hairless-joints.png)

坐姿无毛成猫的下巴微微向前探出，颈侧从下颌后方连到肩胸。尾巴从后腰正中伸出，绕过后腿，向前爪旁的尾尖逐渐收细。趴姿幼猫的尾巴则沿地面向后舒展。[无毛猫颈部和尾巴的前后对照](cat-lab-hairless-neck-tail.png)

无毛成猫的颈围以这只猫的下颌宽度和深度为基础，体态丰盈度只略微增加颈部厚度。窄脸胖猫仍有宽肩，颈侧在下巴下方收拢，侧面的后颈向肩胛逐渐展开。[窄脸胖猫的正面、斜前和侧面对照](cat-lab-hairless-neck-proportions.png)

**正面版已选定。** 实验室默认加载正面版，作为成猫和幼猫格内外观的基础。从顶部切换到「多视角试版」时，会沿用当前个体的外观参数和相机角度，便于继续对照。[实验室](../tools/cat-lab/index.html) · [旋转视角实拍](cat-lab-rotation-study.png)

**物品栏规格（2026-11-20 确认）**　幼猫正面趴姿，占 2 格宽、1 格高。成猫正面坐姿，占 2 格宽、4 格高。

**早期骨架与外皮试稿（2026-11-19）**　以下剪影、橘虎斑和亲子试绘保留了当时幼猫侧身、横占三格的设计，可用来查阅姿势控制点和遗传外观。当时确认的骨架以加入肥猫前的侧身瘦猫为准，头颈、脊柱、前后肢和尾巴都有固定的姿态控制点。后续外皮和胖瘦造型均以这组坐标为参照。[定稿剪影与关节图](cat-skeleton-review.png) · [关节坐标与出图程序](../tools/cat_skeleton.py)

**2026-11-19 已确认橘虎斑基础外皮。** 程序在定稿轮廓内绘制毛色，以脊柱和尾线定位条纹，以爪端定位白袜。同一份基因决定幼猫与成猫的条纹数和弯曲程度。[橘虎斑定稿](cat-coat-study.png) · [外皮绘制程序](../tools/cat_coat_study.py)

**圆胖外皮修订稿待审。** 圆胖成猫的脸颊向两侧和下巴展开，侧面能看见胡须根部微微鼓起。幼猫趴着时脸颊更靠近前爪。程序在脸部坐标中画出眼睑、瞳孔与高光，虹膜沿用个体的眼色。清瘦和圆胖共用姿势骨架，体型基因决定两端之间的外皮形状，毛纹、明暗与腿部轮廓随之移动。三档对照使用相同的橘虎斑毛色基因与绘制比例。[圆胖幼猫与成猫近照](cat-round-study.png) · [三档体型与格内效果](cat-body-study.png) · [体型绘制程序](../tools/cat_body_study.py)

早期亲子试绘保留作遗传实验参考。[早期亲子试绘](cat-genetics-preview.png) · [绘制原型](../tools/cat_preview.py)

**候选路线：三维塑形，二维显示（待验证）。** 以第一版瘦猫的剪影和关节位置作参照，在同一张立体网格上雕出清瘦、适中和圆胖的身体，沿用已定坐姿。先用固定正交相机拍三只无花纹的灰模，缩到成猫 2 × 4 格，检查腮颊与颈毛的交界、胸腹与前后腿的遮挡。幼猫按同样方法检查正面趴姿缩到 2 × 1 格后的耳尖、前爪和身体轮廓。脸型和体况分别由基因组合表达；需要时为宽脸与厚颈同时出现的情况雕一个修正形态。虎斑和白斑按猫体表坐标计算，同一个体读档应重现原来的花纹。手工雕塑的体态仍待定稿；下方交互原型用程序曲面检验表现参数。[Blender 形态键说明](https://docs.blender.org/manual/en/5.0/animation/shape_keys/shape_keys_panel.html)

实机先测同一物品类型的两只猫能否同时显示各自算出的图标，搬动、读档后仍匹配原个体，并保持当龄的固定占格。通过后，首次显示或可见外观变化时渲染并缓存图标。官方常用的物品贴图接口从透明度推算格子形状，动态个体图和固定占格的组合仍待验证。[官方物品精灵图说明](https://github.com/dragonpan2/probably-stolen-modding/blob/f1ec77b3021af7124d01478aae58e7a754d43609/ModdingGuide.zh-CN.md#物品精灵图)

调整成猫原画后，在项目根目录运行 `python tools/fit_kitten_paint.py`，按幼猫的趴姿重建贴图。再运行 `python tools/pack_cat_paint.py`，更新面板离线加载的图集。

**在外观实验室试配。** 可以先选短毛、虎斑和白手套，旋转模型看条纹如何绕过体侧和尾巴。再切换长毛看颊边与尾巴的轮廓，或切到无毛看肤色。选异瞳后分别设定猫的左、右眼，格内小图可用来核对正面效果。试三花或拼色时，点「换个分布」可以只重排色块。相同的年龄、花色、配色和花纹编号会重现同一组斑块。单猫模式下，通过本地服务器打开面板时可以复制当前网址，留存这次试配。[猫咪外观实验室](../tools/cat-lab/index.html) · [八种外观组合实拍](cat-lab-appearance.png)

单独查看时，切换年龄会沿用当前表达值。「同场对照」把两只猫放在同一地面，点选年龄即可调整对应个体。旋转主视图或切换灰模时，格内小图仍按实际毛色从正面渲染。实验室面板用于美术评审。游戏里的幼崽仍按双亲序列随机遗传，遗传代码、个体存档与物品图标的实机接入均待验证。[幼猫正面格内实拍](cat-lab-kitten-icon.png)

参考原版老鼠的日末配种。夜间进食结算后，分别查猫窝组和繁育间组。猫窝组包括实际住在猫窝和从猫窝自行外出的猫。繁育间组由实际同住在隔间里的猫构成。两组都要求猫为存活、未绝育且有饱腹值的成年异性，母猫未怀孕时才计入尝试。受孕后清空累计尝试次数。

成功受孕时，按母猫表达出的窝产倾向抽取这一窝为 **1–8 只**，并保存窝数和预产日。隔间提高受孕率，扩建增加摆放空间。基础妊娠用时为两个游戏日，母猫可照常活动。悬停母猫或打开它的遗传图，可看已过天数和总天数。每只幼崽都从双亲独立抽取序列，沿用真实亲缘。具体位点见[窝产倾向](猫猫基因表达规则.md#繁育)。

## 寿命、绝育与死亡

从出生起按游戏日计龄。基础寿命共 **4 个游戏周（28 天）**，基因表达可以改变各阶段的实际时长。同窝猫也可能在不同日子成年、变老。

| 生命阶段 | 基础时长 | 育种与交易 |
| --- | --- | --- |
| 幼年 | 1 周（7 天） | 爱猫者可收购，有幼猫溢价，长至成年才具备育种资格 |
| 成年 | 2 周（14 天） | 爱猫者可收购，未绝育的成年活猫可以育种 |
| 老年 | 1 周（7 天） | 退出育种，出售时有老年折价，老年期结束时自然死亡 |

**钳子可以给猫绝育。** 绝育永久取消该个体的育种资格，并影响此后的生长和性格表现。生长变化体现在后续成长进度，性格变化体现在猫自发选择的行为上。变化的方向与幅度留待试玩确定。

**把活猫拖进原版垃圾桶会遗弃它。** 这只猫从店铺离开，家谱保留它与后代的关系。遗弃的猫仍是活体记录，清洁服务的猫粮兑换只处理死亡留下的猫尸。

任何死因都会留下猫尸。普通顾客只收活猫，猫尸无法出售换钱。玩家可以把猫尸丢进垃圾桶，也可以使用黑市的「清洁服务」。服务收走猫尸后，玩家获得猫粮。老死的猫同样适用。

### 猫窝和繁育隔间

- **本体与猫窝**。猫舍外部占 4×3 格。猫窝初始 8×4，空仓可放四只 2×4 格成猫，开局放两只后还有 16 格可用。幼猫占 2×1，混住按实际占格。每块金属锭在底部加一行，最多扩六次，到 8×10 后停止扣料。外部大小和已有物品位置保持原样。旧档已购尺寸保留，已有高度达到 10 行时停止扩容。
- **繁育隔间**。选中原版「韧棉织物」（`kotton_fabric`）并对猫舍使用，先加建独立的 6×4 库存。每次再用一份织物就向下加一行，共可扩六次，到 6×10 后停止扣料。只有两只 2×4 成猫并排时，6×4 还能摆四只幼猫，升两次到 6×6 可放下整窝八只。每座猫舍先给繁育间投喂，再给猫窝投喂，隔间分别配种。幼猫先落到母猫所在的隔间，挤不下时试同一座猫舍的另一隔间，再放后区柜台。母猫从猫窝外出时仍沿用原猫舍，没有归属时直接到后区柜台。后区柜台也满时丢弃放不下的幼猫，晨报列出数量。

### 猫毛加工器

短毛猫每天掉 1 份毛，长毛猫掉 2 份，无毛猫不掉毛。猫毛每份占一格，基础价 4 信用点，优先落在猫所在容器。容器放不下时尝试后区或店内收纳。两处都满，留待腾出空格后投放。

猫毛加工器单独购买，基础价 300 信用点，普通难度宠物店售价 450 信用点，外部占 3×3。原版电池装在左侧。夜里机器自动收集店内可取的猫毛，每处理 10 份消耗 4 千焦，产出 1 份原版韧棉织物。进料格可取放猫毛，最多平放 40 份。出料格只取成品，可平放 12 份织物。满仓时剩余猫毛留在原处或机器进料格，电量不足时继续保存已有库存。

## 白天，猫自己选地方

营业时，猫按基因表达出的偏好、当下状态和周围发生的事自行活动。猫可能接受玩家抱它，也可能挣开或根本抱不起来。玩家可以给猫吃的、添水和改善猫舍；游戏不给猫指定工作、划禁入区或排班。多种行为可以出现在同一只猫身上。

| 地方 | 可能发生什么 |
| --- | --- |
| 猫舍 | 猫可以进来休息、吃东西。猫舍可加装原版喂老鼠用的同款自动喂食器。基础水及更好的水有益成长，不供水也能长大，只是慢些；喝坏水可能生病，也可能发生基因突变。加装猫爬架后，活跃的猫可以把精力花在攀爬上，少去捣蛋 |
| 货架、箱子 | 猫见到老鼠可能扑上去，成功后像捕鼠夹一样真正抓到那只老鼠。遇到它觉得有意思的货物，也可能伸爪把它摔下去，例如一小瓶梦尘；饿了还会翻找食物偷吃 |
| 展柜 | 开门时有活猫待在展柜里，当天就会来一名爱猫人士。一半机会按随机一只展出猫的年龄吸引相应买家，另一半照常生成来客。原版普通顾客开放后，还有 20% 的机会多来一名普通买家或卖家 |
| 柜台 | 猫自己跳上来亲近客人，可能换来小费或回礼；待腻了就走 |
| 猫猫发电机 | 猫兴起时自己上跑轮，消耗体力、产生可供模组设备使用的电量 |
| 游戏内桌宠 | 猫有时会溜到可拖动的小窗里陪店主。玩家可以抚摸或收起窗口，猫仍按自己的脾气活动 |

掉落与摔坏分开结算。展柜里被踢出的商品仍可落在店里；遇到易碎物时，再按物品的实际反应处理。事件记录标明哪只猫碰了哪件货、最后落在哪里或是否损坏。

## 夜行与猫猫外交

入睡后，猫根据基因显现的夜行倾向、体力和环境，自己决定是否外出以及往哪里走。玩家到次晨才从见闻、实物、来客或投诉得知昨夜的事。夜里去宠物店是店主自己的行程。猫带回的猎物、拾荒物和回礼优先放在后区柜台，柜台满了则放入店内收纳。两处都放不下时保留待投放记录。

在店内其他容器活动的成年和老年猫饿了会回来找吃的。吃到东西后优先回猫窝，放不下便在窝边吃，原来的格子保留。其余成年和老年猫按活跃、好奇和夜行性状决定要不要换窝，可选猫窝、店内收纳、展柜和有空位且允许放猫的自有容器。成功移动后晨报会写它去了哪里。幼猫和繁育间里的猫留在原处。

夜间正常喂食后，饱腹仍在 1–25% 的成年和老年猫还可能到店内能接触的储物格吃掉一份食物或一只活老鼠，也可能出门觅食。饱腹为零的猫当晚离店，饿死在店外，家谱保留亲缘记录。

| 猫自己去的地方 | 可能的遭遇 | 留到次日的痕迹 |
| --- | --- | --- |
| 仓储通道 | 捕猎、叼回口粮，或扑了个空 | 柜台上多了一只老鼠，或有守仓人来道谢 |
| 废料堆 | 翻到旧零件或宝物，也可能累得提前回家 | 后区柜台多了一件零件，猫还在睡觉 |
| 阵营住区 | 拜访熟人、收到回礼，或因翻乱东西招来怨气 | 爱猫者来店、留下委托，或有人拿着坏掉的东西来索赔 |

各阵营的爱猫者按猫的**性格、外观、其他特征以及以往往来**作出不同反应。本版接入下层区和安保岗。受欢迎的夜访和投诉会结算对应阵营的原版声望，个人好感另用于影响之后的拜访结果。每个阵营每晚的基础声望变动合计最多为 2 点，正向或负向都按原版倍率和边界结算。

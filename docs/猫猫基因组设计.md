# 猫猫基因组设计

**2026-11-20 定稿。** 基因组、性状表达和世代选育是《深空猫舍》的核心玩法。玩家通过观察、测序、寻找新血系和选择双亲，把想要的组合一代代育出来。本规格确定首版基因组容量与传递机制。位点编号、等位值和表达条件见[猫猫基因表达规则](猫猫基因表达规则.md)。出现概率和数值幅度由试玩调平。

## 首版位点规模

| 类别 | 数量 | 用途 |
| --- | ---: | --- |
| 常染色体功能位点 | 84 对 | C 12 用于银系毛色，B 12 用于隐性重点色。原有外观 18 项、性格与潜能 8 项、体质与成长 6 项、控制基因 4 项用 79 对。新版窝产量用 3 对原预留位 |
| 常染色体永久中性位点 | 6 对 | 每一位取 0 或 1，随亲本片段遗传。各位的组合可作为测序里辨认血系和片段的标记 |
| 常染色体扩展预留位点 | 1 对 | A 10 暂按中性处理。0 和 1 都可随机生成、遗传及突变 |
| X 独有位点 | 6 个 | 组成 4 项功能。XX 猫在每个位点有两份值，XY 猫有一份 |
| Y 独有位点 | 2 个 | XY 猫在每个位点有一份值，随父系传递 |

基因组仍为 **91 对常染色体二进制位点**。A 至 F 每条染色体的长度依次为 14、17、18、14、14、14 位，每组各有一个永久中性位。中性和预留位点随周围片段一起继承与重组。双击猫可直接看表达出的性状和血亲图，测序取得该个体的详细 0/1 位串。

启用预留位时沿用编号与顺序。新版新开始的妊娠读取母猫原有的 D 10、E 10、F 10 位值；已经在途的旧版妊娠沿用旧数量。已有个体的位串保留。

## 基因组与幼崽继承

每条染色体是一条有序的 0/1 位串，每一位只存 0 或 1。常染色体每组保存两条位置一一对应的位串，同一位置上来自双亲的两位构成一对。幼崽从双亲各获得每组的一条位串。亲本可以在任意两个相邻位之间重组，性状所需的位组合也可被切开或拼到同一条序列上。同窝的每只幼崽独立继承。

配种由一只可育成年的公猫和一只可育成年的母猫完成。母猫成功受孕时，按她的[窝产倾向](猫猫基因表达规则.md#繁育)从 1–8 只中抽取本窝数量并存档。每只幼崽独立抽取双亲传下的序列，再结算突变并登记基因组。物理位可按突变规则在 0 和 1 之间翻转。每个染色体组保留位点顺序和双亲来源。出生时生成的序列及其规则版本写入个体存档，读档恢复同一窝和同一个体。

## 性染色体怎么传

采用简化的 XX / XY 规则。母猫传一条 X，公猫传一条 X 或一条 Y。幼崽得到 XX 就是母猫，得到 XY 就是公猫。母猫的两条 X 可以交换片段，公猫的 X 和 Y 各自传递。

| 基因所在的位置 | 谁能继承 | 怎样表达 |
| --- | --- | --- |
| Y 独有位点 | 公猫的 Y 传给它的每只儿子，可沿父系追溯多代 | 规则可让一份 Y 值直接显现，也可要求其它基因同时凑齐 |
| X 独有位点 | 父猫的 X 传给它的每只女儿。母猫传出的 X，儿子和女儿都能拿到 | XY 猫按这一位点实际有的一份值算表达，XX 猫按两份值算 |
| 常染色体位点，设有性别表达条件 | 儿子和女儿都能继承 | 可以设为只在公猫身上显现。母猫可以携带并传给下一代 |

例如，一条父系可以把某个鼻斑所需的值放在 Y 上，所有儿子都能继承。若显现同时需要某个常染色体位点满足条件，同窝的公猫可能只有一部分长出鼻斑。若想让一只外表普通的母猫把类似鼻斑传给儿子，则可以把所需值放在常染色体上，给表达加上公猫条件。稀有度也可以来自少数初始父系持有目标 Y，找到后便能稳定传给儿子。

## 性状怎样读取基因

每个物理位的 1 为显性，0 为隐性。有两份的位点，0/0 显现 0，0/1、1/0 和 1/1 都显现 1。携带 0 的个体仍可把它传给后代。只继承一份的 X 或 Y 位点按实有的一份读取，只有具备该位点的个体才参与相应规则。

| 表达来源 | 规则示例 | 玩家见到的结果 |
| --- | --- | --- |
| 一对 | 任一份为 1 时显现 1，两份都为 0 时显现 0 | 至少一份抑色位为 1 时开启抑色。B 1 两份都为 0 时显现无毛 |
| 连续多位 | 先逐位合成显性码，再读取指定位置的组合。若规则还要求若干 1 在同一条序列上，另查这些位的亲本来源 | 底色从多位组合得到。斑点虎斑还要求所需的 1 来自同一条染色体 |
| 间隔或跨组的多位 | 读取同一序列上间隔较远的位置，也可跨不同组读取。可要求几项同时满足，或汇总各位的贡献 | 一种特殊花纹可能同时需要底色和白斑范围合适。胖瘦可由多个位置各贡献一点 |
| 控制基因 | 读取指定的位组合，改变某条表达的触发条件、强度或阈值 | 一只猫显示白色被毛，同时减弱与这套毛色共享来源的易躁倾向 |

有多种颜色、形态或强度档位的性状，通过多个位置的 0/1 组合得出表现。增减剂量读取各指定位置上 1 的份数。同一个位点也可被多条规则读取，一条规则能让毛色变白，另一条规则能让应激反应变强。成年阶段才显露的性状到龄后才开始表现。白天与夜间的实际行动还取决于这只猫当下的状态、周围发生的事和它自己的选择。

表达按固定顺序结算。

1. 逐位合成显现值，同时保留双亲传下的原始序列。读取性染色体、年龄和位点，得到待判断的条件值及基础幅度。规则要求显现 0 时，双份位点须为 0/0。规则要求多个 1 位于同一条序列时，检查双亲传下的原始序列。
2. 控制基因按指定目标调节某条效果的触发条件、阈值或幅度，再判断规则是否生效。控制规则读取基因组，并作用于明确的一项效果。这样同一组基因带来的两项表现可以分别调节。
3. 汇总已生效的效果得到可用的性状。体宽等连续值按各来源贡献合成，互斥花色按规则优先级决定显示层。覆盖在下面的花纹仍由对应的基因保留。外观参数交给正面模型，性格和体质交给猫的自主行为与生命周期规则。

## 稀有度从哪里来

| 来源 | 对育种的影响 |
| --- | --- |
| 起始携带少 | 某些等位值较少出现在领养、来访或宠物店的新血系中。碰到合适的亲本可能是最难的一步 |
| 表达条件难凑 | 所需等位值可以分别很常见，落在同一只幼崽身上并同时生效的机会仍然较低。携带片段的猫也可能始终看不出这种性状 |
| 传下整套组合的机会 | 相邻片段排在同一条序列上时较容易一起传下。分散在不同组的条件要分别凑齐。两只显示相同性状的亲本也可能给出不同的育种结果 |

三项独立设定。稀有性状可以难显现、难稳定传递，也可以只在新血系中少见。比如，某个开关位上的 1 在新猫中很少见。该位为 1/0 的猫与 0/0 的猫配对，按简单等概率继承，每只幼崽有一半机会得到 1。另一种花色若需要三个分属不同组的位置均为 0/0，双亲在这三个位置都为 0/1 时，每个位置凑齐的机会都是四分之一，三处同时满足的机会就是六十四分之一。这两个算例用于说明设计，正式分布与表达幅度留待试玩。

部分稀有性状依赖隐性位。梵花要求 C 10 为 0/0，同时凑齐其它花色和白斑量条件。无毛要求 B 1 为 0/0，外观有毛的携带者也能传下这一位的 0。部分缺陷同样由隐性位触发，例如 E 11 为 0/0 时恢复慢，E 13 为 0/0 时饮用坏水更容易生病。其它负面效果仍可由显性位或多个来源叠加触发，例如抑色位 B 17 的 1 所带来的易躁。

## 纯白、易躁和控制基因

先把「脾气不好」落到可观察的表现上。易躁高的猫被抱或频繁打扰时更可能很快挣开，平静时照样可能亲近人。一套抑色组合能让底下的虎斑或拼色被白色盖住，同时提高易躁基线。同样看起来全白的猫也可以由另一套毛色或白斑组合显现，是否易躁取决于它实际携带的表达来源。

| 表达条件 | 毛色 | 易躁倾向 |
| --- | --- | --- |
| 抑色生效，未开启缓冲 | 纯白 | 明显提高 |
| 抑色生效，一级缓冲 | 纯白 | 仍提高，幅度减弱 |
| 抑色生效，二级缓冲 | 纯白 | 抑色带来的加成抵消，仍体现其它基因与当下状态 |
| 抑色未生效，携带缓冲位 | 由它自身的毛色规则决定 | 沿用其余基因给出的易躁倾向，缓冲位仍可传下去 |

此例的缓冲基因和抑色组合分属不同组，可以独立遗传。抑色组合的两项效果拥有同一个遗传来源。缓冲只调整抑色组合带来的那部分易躁。其它血系如果需要把一组值稳定传下去，就把这些值安排在相邻位置。

在所列位点按继承取值的两代算例中，白猫的两份缓冲片段都是 00，与两份都是 10 的非白猫配种。这一窝每只幼崽都有 00 和 10 两份片段，取得一级缓冲。再从中选一只继承了抑色的白猫，与两份缓冲片段都是 01 的非白猫配种。后代若同时继承抑色位上的 1、亲本传来的 10 和 01，缓冲的两个位置就各有一份 1，达到二级。玩家可以靠测序选双亲，也可以观察几代猫的表现。

## 玩家怎样看懂

- 双击猫打开最近三代的[血亲遗传图](玩法核心骨架.md#看一只猫读懂一只猫)。点击带立绘的节点，右侧展示外观、性格、习性与状态，窝产潜力按档展示。母系和父系使用不同颜色连线。
- 每只猫首次被基因扫描仪实际扫描时保存详细 0/1 序列，标明常染色体的双亲来源、X 和 Y。根据位点可追踪父系 Y、隐性携带和外观覆盖前的花纹。祖先离店或死亡后，图中仍保留这只猫已取得的测序结果。
- 适龄公母猫在各自的繁育组中自行配种。繁育间只匹配同住的猫，猫窝组也包括从猫窝自行外出的猫。幼崽出生后，图上才出现它与亲本的关系。玩家可以比较同窝幼崽，逐代追踪外观和性格何时一起出现、何时分开。

## 核心验收

| 测试场景 | 通过条件 |
| --- | --- |
| 同窝和读档 | 同窝的每只幼崽独立继承片段，家谱指向双亲。同一窝读档后恢复为同一批幼崽，各自的基因和外观保持一致 |
| 单对、连续片段与跨组组合 | 0/0 显现 0，其余双份组合显现 1。多种表现由多位组合得出。要求同一条序列时，只有指定的 1 位于同一条上才起效，重组能把组合拆开或拼齐 |
| 隐性性状与缺陷 | 无毛、恢复慢和坏水敏感各自只在对应的双份位为 0/0 时触发。携带者可经测序辨认，仍能把 0 传给后代 |
| 父系传递和性别表达 | 父系 Y 随父传子。父系 X 传给女儿。母猫携带的限公猫表达值可以传给后代，符合条件的公猫显现性状 |
| 纯白联动与缓冲 | 在抑色条件相同的情况下，三个缓冲档位得到相同白色和逐档变化的易躁倾向。测序能区分这些位组合 |
| 中性位点与扩展 | 仍预留的位点和永久中性位点都可遗传两种值，只更改这些位时测序读数变化，已表达性状一致。启用窝产量后仍按原编号读回 91 对位点 |
| 性状、测序与育种揭晓 | 双击猫可见表达性状和血亲。图中只有实际测过的个体可读详细 0/1 序列。核对两只已经死亡的祖先，一只留有测序快照，另一只始终无详细序列。幼崽出生后才显示自己的立绘和亲缘线 |

## 百代遗传模拟

百代图谱保留固定种子 20261120 在当时规则下的实跑记录。当时六个预留位固定为 0。实跑从一只 G0 起点猫出发，每一步给主藤上的猫随机生成一只异性配偶，由一只幼崽继续接到下一代。至 G100 共有 101 只主藤猫和 100 只外来配偶。每次传递可重组的染色体有 35% 的机会在一个随机位点间重组，允许突变的每份位点有 0.1% 的翻转机会。

从模组 0.2.62 起，猫舍新生幼猫在继承后，每个来自亲本的位独立以 0.2% 概率翻转。公猫有 190 个传递位，母猫有 194 个，单只至少发生一处突变的概率分别为 31.64% 和 32.19% 左右。翻转位置在出生时写入个体记录。测序页统计本代突变数，并用紫框标出具体位点。宠物店和开局生成的初代猫显示「初代个体，无亲本对照」。

起点猫和外来配偶每份 B17 抑色值的随机供给率为 2.5%，每个 B04 稀释位为 12%。这是演示供给分布。被继承的位点仍按既定显隐性与组合表达。图谱的纯白统计用实际显示的白色被毛，奶油色单独计数。模拟器的现行规则允许所有位点取 0 或 1，中性和预留位在新血系中每份默认以 50% 概率取 1。
